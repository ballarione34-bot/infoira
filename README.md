# INFOIRA — Digital Marketing & Education website

Premium responsive multi-page static website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About INFOIRA
- `services.html` — Digital marketing services
- `education.html` — Education & training
- `gallery.html` — Gallery placeholders
- `news.html` — News & insights
- `contact.html` — Contact / enquiry

## Customise before publishing
1. Replace sample phone, address, email and business hours with official INFOIRA details.
2. Replace sample copy, training programme details and news items with confirmed information.
3. Replace gallery colour tiles with your actual project images and photos.
4. In `assets/script.js`, replace `hello@infoira.com` with your actual enquiry email address.
5. The contact form is a front-end demo that opens the visitor's email app. For submissions without an email app, connect a service such as Formspree or your own backend.

## Publish free with GitHub Pages
1. Sign in at https://github.com/ (create an account if needed).
2. Click **New repository**. Name it `infoira-website`, choose **Public**, then create it.
3. Open the new repository and choose **Add file → Upload files**.
4. Extract this ZIP on your computer. Upload all files and folders inside the extracted folder. Ensure `index.html` is in the repository root.
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/ (root)`, then click **Save**.
9. Wait for deployment. GitHub Pages will display your website address in Settings → Pages.
10. Open the published URL and test each page and contact link.

Typical project URL:
`https://YOUR-USERNAME.github.io/infoira-website/`

For a user-site repository named `YOUR-USERNAME.github.io`, the URL is:
`https://YOUR-USERNAME.github.io/`

## Custom domain (optional)
Add your purchased domain under **Settings → Pages → Custom domain**, configure DNS using GitHub's instructions, then enable HTTPS when available.
